# Note (Notiz)

A short, self-contained note — a single thought, reminder, or captured snippet.
Created as a Trilium **text** note, so write the body as light HTML (that is what
Trilium's editor stores).

## Format
- Lead with the point in the first sentence; no long preamble.
- One topic per note. If it needs sections, it is a Knowledge Base entry instead.
- Body is simple HTML: `<p>` paragraphs, `<ul>`/`<li>` for lists,
  `<strong>`/`<em>` for emphasis. Do **not** add a heading — the note title is
  the heading.
- Keep it under ~150 words.

## Conventions & Voice
Write in **German** unless the author has asked for another language.

A note captures a thought; it is not addressed to a reader, so there is normally
no second person in it at all. Do not ask for an address form — a note is too
short to be worth a round trip. Keep the tone plain and factual.

## Example body
```html
<p>Refill the espresso beans before Monday — the office order ships Friday.</p>
<ul><li>Dark roast, not the decaf</li><li>2 kg bag</li></ul>
```
